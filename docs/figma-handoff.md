## Что переносить

Нужен один основной продуктовый экран с адаптивными вариантами:

1. `Desktop / Event Board / 1440`
2. `Mobile / Event Board / 390`

4. `Event Editor Modal / Moderator`
5. `Owner Panel / Members & Roles`

## Структура главного экрана

### 1. Sticky Header

- Логотип
- Название "Доска мероприятий"
- Кнопки входа/регистрации
- После авторизации: имя пользователя, роль, выход

### 2. Hero Section

- Большой градиентный блок в фирменных цветах
- Крупный слоган о календаре, фото, ролях и посещаемости
- 4 статистические карточки:
  - события
  - команда
  - штаб
  - отклики
- CTA-кнопки:
  - перейти к ближайшей дате
  - присоединиться

### 3. Spotlight Card

- Выбранное ближайшее мероприятие
- Большое фото
- Категория, дата, место
- Заголовок и краткое описание
- Мини-метрики:
  - придут
  - не смогут
  - фотографии

### 4. Calendar Board

- Заголовок месяца
- Стрелки переключения месяцев
- Кнопка "Сегодня"
- Бейджи с количеством событий в прошлом и следующем месяце
- На мобильном варианте обязательно добавить подсказку:
  - "Листайте календарь по горизонтали"

Состояния ячейки календаря:

- `Default`
- `Selected`
- `Today`
- `Outside current month`
- `Has events`
- `Moderator view`

Состав ячейки:

- круг с числом
- маленький label состояния
- до 2 карточек мероприятий с временем и названием
- компактный вид для mobile

### 5. Event Detail Panel

- Пилюли со временем событий выбранного дня
- Заголовок выбранного мероприятия
- Краткое и полное описание
- Метаданные:
  - дата
  - время
  - локация
  - организатор
- Блок RSVP:
  - "Я приду"
  - "Не смогу"
- Счётчики:
  - придут
  - не смогут
  - свободно мест

### 6. Info Section

- Блок "Как это работает"
- 3 шага:
  - регистрация
  - выбор даты
  - отметка участия

### 7. Upcoming Feed

- Лента ближайших мероприятий
- Фото, дата, время, заголовок, короткое описание

## Дополнительные экраны

### Auth Modal

- Переключатель `Регистрация / Вход`
- Поля:
  - имя
  - email
  - пароль
- CTA на всю ширину
- Информационный блок о ролях

### Event Editor Modal

- Заголовок для создания/редактирования
- Поля:
  - название
  - категория
  - место
  - организатор
  - лимит мест
  - дата
  - время начала
  - время окончания
  - краткое описание
  - полное описание
  - загрузка фотографий
- Кнопки:
  - отмена
  - удалить
  - сохранить

### Owner Panel

- Поиск по участникам
- Список пользователей
- Переключение роли:
  - activist
  - moderator
- Owner остаётся отдельной защищённой ролью

## Адаптив

### Desktop

- Основная сетка: hero + spotlight в 2 колонки
- Ниже: calendar + detail panel
- Широкие карточки и большие радиусы

### Mobile

- Всё в одну колонку
- Hero и spotlight вертикально
- Calendar со swipe по горизонтали
- Ячейки календаря короче и компактнее
- Подробности мероприятия идут сразу под календарём

## Что важно сохранить в Figma

- Контрастный фирменный сине-красный hero
- Стеклянные белые surface-контейнеры
- Верхний sticky header
- Конденсированные uppercase-заголовки
- Чёткое разделение ролей:
  - гость
  - активист
  - модератор
  - владелец
